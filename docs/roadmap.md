# Roadmap

| Step | Scope | Status |
|---|---|---|
| 1 | Daemon, agents with avatar/name/role, chat, approvals, usage, notch on every screen with styles, minimal board | **Done** |

Claude Code agents can share one computer and take turns (2026-10-24). Virtual Codex stays disabled. See [computers.md](computers.md). Later: macOS VMs (Lume). | **Done** |

| 5 | **Architect.** Create agents by describing what you need; it asks a few questions, proposes the agent and creates it | **Done** |
